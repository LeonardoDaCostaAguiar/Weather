# Weather

[![iOS CI](https://github.com/LeonardoDaCostaAguiar/Weather/actions/workflows/ios-ci.yml/badge.svg?branch=main)](https://github.com/LeonardoDaCostaAguiar/Weather/actions/workflows/ios-ci.yml)

Weather is an iOS weather app that shows current conditions and forecasts for the coming days. It retrieves weather data from the [Open-Meteo API](https://open-meteo.com/) and presents it in a SwiftUI neumorphic interface with light and dark modes.

## Features

- View current weather conditions and a map
- Check the forecast for the coming days
- Support for English, Brazilian Portuguese, and Spanish
- Choose between two widget sizes
- Use the app in light or dark mode

## Requirements

- iOS 17.0 or later

## Architecture

The app follows the Model–View–ViewModel (MVVM) architecture, separating the presentation layer from the app’s data and logic.

## Built With

- Swift
- SwiftUI
- MVVM
- [Open-Meteo API](https://open-meteo.com/)
- Neumorphic visual design
